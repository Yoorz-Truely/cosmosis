# Cosmósis

Cosmósis is the project framework of Sau, an IDE for 3D built on Blender's source: how a project folder is laid out, the manifest and lockfile, packages, templates, and the `sau` command. It plays the part Next.js plays for web apps; the language it lays out is Null (`/Users/yoorztruely/Projects/Null`).

Nothing is built yet. The specification is [docs/spec/cosmosis-v0.md](docs/spec/cosmosis-v0.md). The plan for this repository is in Sau's `docs/REPOSITORIES.md` (`/Users/yoorztruely/Projects/Sau`).

Cosmósis is MIT-licensed ([LICENSE](LICENSE)). Sau itself carries Blender's GPL.

cargo build
cargo test
